# アートサロン空 — Webサイト試作

奈良県奈良市学園北1丁目6-15にある「アートサロン空」の新サイト試作です。

## 方針

- スマートフォンを含めて読みやすい
- 高齢者にも情報を探しやすい
- レンタルスペースを用途別に理解できる
- イベント情報を後から更新しやすい構成にする
- 電話予約を主要な導線にする
- SNSはアカウント確認後にリンクを追加する
- GitHub Pagesで公開できる静的サイトを想定

## 注意

現在はデザイン・情報構成を確認するためのデモです。
料金、営業時間、アクセス表記などは公開前に運営者による最終確認が必要です。
写真は実際の施設写真へ差し替えてください。
